Connecting to the Glyph

  1. Hold RT2 while plugging the Glyph into USB to enter Configurator mode.
  2. Click Connect in the toolbar and select the Glyph serial port.
  3. Click Load Config to read the current profiles from the device.
  4. Edit your profiles, then click Save to Device to write the new config.

Editing Profiles

  • Click a button on the controller layout to assign or remap it.
  • Use the right panel to edit mode, backends, SOCD rules, and lighting.
  • A colored outline around a button indicates it is active (mapped) in the profile. The outline color reflects the LED color set for that button in Button Lighting.
  • Plain dark gray buttons are unmapped (disabled) in the profile.
  • Switch Button Display Style (Xbox / PlayStation / Switch) below the controller to change how the mapped buttons are labelled.
  • Right-click a profile in the sidebar to Rename or Duplicate it.

Config Files

Use Export JSON / Import JSON to save and restore configs offline.

The JSON format is compatible with the official Glyph Configurator.
